## 9. 技术选型总结

### 9.1 技术栈总览

| 层级 | 技术选型 |
|------|---------|
| **前端框架** | Next.js 14 + React 18 |
| **UI组件库** | shadcn/ui + Tailwind CSS |
| **后端框架** | NestJS + TypeScript |
| **数据库** | PostgreSQL + MongoDB + Redis |
| **搜索** | Elasticsearch |
| **分析** | ClickHouse |
| **向量** | Milvus |
| **LLM** | Claude + GPT-4o |
| **语音** | 讯飞 / 阿里云语音 |
| **容器** | Docker + K8s |
